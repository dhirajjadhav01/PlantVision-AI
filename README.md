# PlantVision AI 🌿

PlantVision AI is a Deep Learning based plant disease detection system developed using TensorFlow, MobileNetV2 and Streamlit.

<img width="958" height="451" alt="image" src="https://github.com/user-attachments/assets/057c02a1-aef6-457a-bc9b-4cad3f5f4807" />


## Features

- Tomato leaf disease classification
- Early Blight detection
- Late Blight detection
- Healthy leaf detection
- Confidence score
- Class probability visualization
- Agricultural decision-support summary
- Streamlit web interface

## Model

The system uses MobileNetV2 with transfer learning.

Input size: 224 × 224

Classes:
- Early Blight
- Late Blight
- Healthy

Best validation accuracy: 95.11%

## Technologies

- Python
- TensorFlow
- Keras
- MobileNetV2
- NumPy
- Pandas
